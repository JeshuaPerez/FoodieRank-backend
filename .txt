 Se agrego un controlador para el manejo de errores

 src/models/favorito.model.js

 Relación usuario–favorito. Una sola 
 colección para restaurantes y platos, el

 Busca en la base de datos la craecion en la

 favorito, y que responder al usuario cuando este

 Este documento es el encargado de que se valide

 usuario cree una seccion de favoritos sea un 
 unico dueño.
